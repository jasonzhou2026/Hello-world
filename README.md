# 训练与营养记录

一个本地优先的健身与营养记录 PWA，面向手机快速记录，同时保留桌面周报与本地数据管理能力。

## 版本

- V1：Git 标签 `v1.0.0`，保留最初版本。
- V2：Git 标签 `v2.0.0`、分支 `codex/release-v2`，保留三动作训练矩阵、数据管理和 3D 肌群图。
- 原版 V3 UI：Git 标签 `v3.0.0-ui-preserved-20260929`，保存调整前的界面。
- V3.1：分支 `codex/redesign-v3`，弹窗登记、独立每日时长、PDF/Word 导出和 iOS 工程。
- V3：开发分支 `codex/redesign-v3`，保留原有记录、统计和本地数据功能，更新视觉设计；是否上线以 GitHub Pages 的发布分支为准。

## V3 视觉设计

以黑色点阵背景、粉紫与靛蓝渐变卡片为主，使用柔亮边缘、深色中心和银灰半透明面板营造层次，搭配点阵数字与荧光黄进度条、按钮。肌群视图延续旋转与正反面查看。手机布局适配安全区域，表单、图表和数据管理保持原有功能。

## 功能

- 食物记录：热量、蛋白质、碳水、脂肪、膳食纤维、糖、钠、钙、铁、镁、钾、锌、维生素 A/C/D/B12。
- 记录管理：食物、力量和户外训练均可编辑、覆盖保存或单条删除。
- 训练记录：力量动作逐个通过弹窗添加，每个动作支持六组独立重量和次数、左右重量；户外活动单独登记。页面最下方登记当天总时长，覆盖旧记录的时长汇总；旧多动作记录仍可编辑。
- 自动计算：摄入热量、训练消耗估算、净热量、力量训练容量。
- 总览：当日能量、容量摘要和可旋转 3D 肌群记录图；食物页显示营养进度，训练页显示今日目标，报告页显示五次训练对比。
- 周报图表：训练项目分类、摄入 vs 训练、净热量、蛋白质、力量容量，以及合并显示的有氧距离与时长。
- 报告导出：PDF 图表、可编辑 Word 文本、Excel 明细；PDF/Word 仅导出选中日期所在周。
- 数据管理：点击按钮打开日期范围预览、删除与 JSON 全量备份/合并恢复。
- 设置：体重、热量、宏量/微量营养目标、目标动作与个人备注。
- PWA：支持本地安装、离线缓存、IndexedDB 本地保存。

云同步、账号和 AI 食物识别不属于当前静态版本。下一阶段的数据边界与接口草案见 `docs/architecture/future-services.md`。

## 本地运行

电脑本机访问：

```sh
npm run serve
```

打开：

```text
http://localhost:4173/
```

手机同 Wi-Fi 临时访问：

```sh
npm run serve:lan
```

然后在手机打开电脑局域网地址，例如：

```text
http://192.168.1.3:4173/
```

## GitHub Pages 部署

这个项目是纯静态站点，不需要构建步骤。

1. 在 GitHub 创建一个空仓库。
2. 把本地项目推送到仓库的发布分支；V2 使用 `codex/release-v2`，V3 使用 `codex/redesign-v3`。
3. 进入仓库 Settings -> Pages。
4. Source 选择 `Deploy from a branch`。
5. Branch 选择需要发布的版本分支，目录选择 `/ (root)`。切换到 V3 会更新线上页面；保留 V2 分支和标签可继续查看原版。
6. 保存后等待 GitHub Pages 发布。

发布地址通常是：

```text
https://你的用户名.github.io/仓库名/
```

更新后，已安装的 PWA 可能先显示旧缓存；联网打开一次，再关闭并重新打开即可载入新版。无需清除网站数据。使用原网址和原浏览器时，本地训练与食物记录会继续保留；代码发布不会上传这些记录。

## iOS App

原生外壳使用 Capacitor 8，页面和数据处理代码与 PWA 共用并打包离线资源。PDF、Word、Excel、JSON 使用系统分享面板。首次安装原生 App 不写入演示数据。

```sh
npm ci
npm run ios:sync
npm run ios:open
```

PWA 和原生 App 的本地数据库相互独立，从 PWA 迁移前请导出 JSON，再在原生 App 的报告 → 数据管理中导入。签名、构建验证和中国区上架状态见 [架构与上架复核](docs/architecture/app-store-readiness.md)。本地隐私和支持页面为 `privacy.html`、`support.html`。
