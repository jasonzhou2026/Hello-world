隐私说明

适用版本：3.1 · 更新日期：2026 年 9 月 29 日

记录保存在你的设备

你输入的食物、营养、训练、体重、目标和备注仅保存在当前设备的应用本地存储中。应用没有账号、广告、分析 SDK 或云同步；这些记录不会发送给开发者。我们不请求相机、麦克风、位置、通讯录或健康数据权限。

导出与分享

PDF、Word、Excel 和 JSON 文件在设备上生成。仅当你主动导出或通过系统分享面板选择接收方时，文件才会被保存或交给所选服务。请自行决定是否分享含个人记录的文件。iOS 分享使用临时文件，分享结束后清理。

桌面小组件

iOS App 与它的小组件通过本机专用共享空间读取今日目标、重量进度和按日期保存的完成状态。共享范围仅限本 App 及其小组件，不会发送给开发者或其他应用。添加小组件后，这些内容会显示在主屏幕上；你可以随时移除小组件。

存储、删除与迁移

你可以在报告 → 数据管理中删除记录或导出、导入 JSON 备份。应用内删除会把记录标记为已删除，不再参与显示、导出和统计。卸载原生应用或清除网站数据会移除该设备中的本地存储；操作系统或你另存的备份可能仍保留副本，应在相应位置管理。换设备、重装或从 PWA 转入原生 App 前，请先导出 JSON，再在新安装中导入。

网页版本与外部链接

网页版本加载文件时，托管服务可能处理网络请求的 IP 地址等基本访问日志；训练和食物记录仍保存在本机。原生 App 的记录功能可离线使用。主动打开 GitHub 支持等外部链接后，相关服务按其自身隐私政策处理访问。

联系与更新

可通过项目支持页面反馈问题。请勿在公开反馈中上传私人训练记录、健康信息或备份文件。本说明将在功能和数据处理方式改变时更新。
